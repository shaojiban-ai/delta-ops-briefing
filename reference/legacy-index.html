// 04 — ONBOARDING

国际服第一周

01
下载与加速器

国际服与国服账号不互通，需走海外客户端 / 主机 / 手游三端任一。延迟敏感，建议配合稳定加速器使用。

02
先打全面战场

不要直接进烽火地带送装备。先在全面战场熟悉枪感、键位、载具，顺便攒哈弗币。

03
跑刀积累哈弗币

穿廉价装进入常规零号大坝跑刀。学会识别协议箱、保险柜、电脑这些高价值交互点，撤离比击杀更重要。

04
学会看物价

同一个东西在不同物资点的价值差距巨大。先记住 T0「大红」清单和当前周交易行均价，再决定背什么走。
